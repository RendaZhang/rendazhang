# Certification page

- Astro renders the credential, the locally served badge, both official verification links, and the
  coverage note in the initial HTML. AWS provides the badge artwork on its
  [Solutions Architect – Associate page](https://aws.amazon.com/certification/certified-solutions-architect-associate/).
- The availability, fault-isolation, and cost examples cite the AWS SAA-C03 exam guide. The
  `#cert-coverage` disclosure uses native details and summary.
- The badge sits beside the dated record and verification links on wide screens. On phones
  it precedes those facts in the same credential panel. The coverage note sits below the
  credential. The active palette supplies the page accent.
